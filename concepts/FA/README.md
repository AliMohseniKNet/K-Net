# 🇮🇷 مفاهیم و مقالات فارسی K-Net

این پوشه شامل نسخه‌های فارسی مقالات و مفاهیم پروژه K-Net است.

## هدف

نسخه اصلی مقالات به زبان انگلیسی و در قالب Markdown در پوشه `en` نگهداری می‌شود. از آنجا که GitHub پشتیبانی محدودی از متون راست‌به‌چپ (RTL) و اسناد فارسی پیچیده دارد، نسخه‌های فارسی به صورت فایل‌های Word (`.docx`) و در آینده در صورت نیاز به صورت PDF نگهداری می‌شوند.

## ساختار

* `paper_01.docx`
* `paper_02.docx`
* `paper_03.docx`
* ...

هر فایل معادل فارسی نسخه انگلیسی همان مقاله در پوشه `en` است.

## نکته

در صورت وجود اختلاف بین نسخه‌های فارسی و انگلیسی، نسخه انگلیسی به عنوان نسخه مرجع (Reference Version) در نظر گرفته می‌شود.
